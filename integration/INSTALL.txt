Reez Rust Output 0.3.3 — C build output conversion

Windows x64 / EEZ Studio 0.29.0
Requirements: an x64 WSL distribution with Python 3.11 or newer.
For the default Rust compile-check, install Rust/Cargo in that distribution.
The ZIP includes C2Rust, Clang libraries, an LVGL 9.5 header SDK and locked Rust
support dependencies. No separate Node installation or MCP token is needed.

1. If an older Reez version is installed, close EEZ Studio, extract this ZIP,
   and run install.ps1 from PowerShell. It removes other folders with the same
   Reez ID and old Yarn registrations that can reactivate an older adapter.
   New installations can import this ZIP using EEZ Studio's Extensions Manager
   under Project Editor Extensions.
2. Save open work, then restart EEZ Studio.
3. Open a saved project and click Rust output in the top toolbar.
4. Enable Rust output and keep rust-src, or choose another separate directory.
5. For PC GUI tests, leave compile_commands.json blank. For firmware, choose
   the database generated by that board's C build so LVGL settings match.
6. Check installation, Save, and press the normal Build button.

Existing C files remain in their configured directory. Reez reads those files
and generates a separate Rust Cargo crate containing src/*.rs and lib.rs.
Only a successful conversion and enabled compile-check produce overall success.
Old Rust output is retained after a conversion/compilation error.

0.2's restricted EEZ JSON generator is no longer the extension's build backend.
There is no action/variable/widget allowlist. C++ source/EEZ Flow C++ is explicitly
unsupported by this frontend; such a build fails instead of skipping the file.
Native application callbacks and external fonts still need definitions, just as
with the original C build. Read SUPPORT.md before integrating into firmware.

Updates: install a newer ZIP and restart Studio. Project reez.json is retained.
The installer can run with a one-process policy override if Windows blocks the
script: powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\install.ps1
Uninstall: use Extensions Manager or run install.ps1 -Uninstall after closing Studio.
Generated files and project settings are retained.
